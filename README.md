# Smart Job Portal

## Project Overview

Smart Job Portal is a web-based job portal project developed using HTML, CSS, JavaScript, and Bootstrap. It provides a simple interface for users to explore job opportunities and register through a responsive web interface.

## Features

- User-friendly job portal interface
- Job opportunity browsing interface
- User registration page
- Responsive design for different screen sizes
- HTML, CSS and JavaScript based frontend
- Bootstrap-based responsive components

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
